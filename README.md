# Launch Countdown

A countdown timer for a campaign or product launch. Set the campaign name and launch date, and it counts down live.

## How to run

Double-click `index.html` to open it in your browser. No installs needed.

## Practice ideas (make a change on a branch, then merge it)

1. Change the default heading "Campaign Launch" in `index.html`
2. Change `DEFAULT_DAYS` in `script.js` from 7 to 30
3. Change the background color in `style.css`
